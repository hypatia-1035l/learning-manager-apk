# 秋风筑物词库 · 形式调整方案（草案 v1）

> 2026-09-22　针对 `14_秋风筑物/04_创作辅助/灵感/01_词库/`
> 现状：**219 个文件 / 2974 词条 / 52 个前缀组**

---

## 一、问题诊断

### 1. 52 个前缀组其实是「三种东西」混在同一层

| 类型 | 前缀 | 数量级 | 性质 |
|---|---|---|---|
| **维度** | 人物·社会·世界·物品·事件·地点·自然·文化·生活·关系·限制 | 11 组 / 116 文件 / 1590 词条 | 一个对象类别（**可复用**） |
| **题材** | 修仙·宅门·民国·无限流·星际机甲·科举·西幻… | 35 组 / 97 文件 / 1315 词条 | 一个世界观的标签（**不可复用**） |
| **叙事技巧** | 短篇·套路·知乎盐选·副本·悬疑 | 5 组 / 19 文件 / 221 词条 | 怎么写（非设定） |

`人物` 和 `修仙` 摆在同一层级，语义根本不同 → 分类列表膨胀到 60 个，且无法用同一套规则调用。

### 2. 关键发现：题材组内部，本来就是按维度组织的

看几个题材组的三件套，**第二部分已经在说维度了**：

| 题材 | 文件们 | 内部维度 |
|---|---|---|
| 星际机甲 | `机甲与军校世界` / `机甲师与军校人物` / `星域战争与虫族威胁` | 世界 / 人物 / 事件 |
| 无限流 | `副本规则与玩家生态` / `玩家与怪物人物` / `副本事件与世界线` | 世界 / 人物 / 事件 |
| 刑侦 | `物证链与现场勘查` / `人物与刑警队生态` / `案件叙事钩子` | 事件 / 人物 / 叙事 |
| 豪门 | `资本家族与名流世界` / `人物群像与继承人生态` / `社交场域与联姻钩子` | 社会 / 人物 / 社会 |

**也就是说：「题材」被错误地提到了分类层级，而它本该是「维度之上的一个筛选标签」。**

### 3. 后果

- 应用里分类 60 个（刚做完的「标签筛分类」只是缓解，没治本）
- 同一个「人物」维度散在 20+ 个题材组里，抽词时抽不到全量
- 题材本身无法被随机抽中（它不是词条，只是文件夹名）

## 二、目标结构

```
┌─ 维度（category）── 决定词库进哪个池、怎么抽         12 个左右
│    人物 / 世界 / 社会 / 事件 / 地点 / 物品 / 自然 / 文化 / 生活 / 关系 / 限制 / 叙事技巧
│
├─ 题材（tag + 独立词条池）── 标识适用范围，且本身可抽
│    修仙 / 宅门 / 民国 / 无限流 / 末世 / 星际机甲 / 科举 / 西幻 …
│    ① 作为词库 tags → 应用里可筛、模板里可过滤
│    ② 独立成「题材」词库 → 随机系统可以直接抽出一个题材
│
└─ 词条（words）── 内容不变
```

**随机组合示例**（这正是结构调整后才成立的）：

```
抽题材 →「修仙」
抽世界 →「修炼境界」
抽人物 →「先天资质」
组合 → 修仙世界的修炼体系 + 资质设定
```

## 六、执行口径（三选一，请拍板）

| 口径 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A · 最小改动** | 只改文件的 **category**（维度）+ 加 **tag**（题材），文件名与词条**一律不动** | 源库结构零损伤、可回退 | 「人物」维度仍是 23 个独立文件，抽词要靠「按维度合并抽取」 |
| **B · 按维度重组** | 同维度的题材文件**合并**进该维度词库（如各题材的"人物类"并入 `人物_*`） | 每一维更完整、抽词直接 | 丢题材来源、文件大改、模板映射要重写 |
| **C · 折中（推荐）** | 保持文件独立 → 改 category=维度 + tags=[来源, 题材]；**再建「题材」池**；应用侧用「按维度筛出多个库一起抽」 | 信息不丢、可筛可抽、模板映射基本不动 | 需在应用/模板里支持「多库合并抽取」 |

**我的建议是 C**：文件不动 = 不碰你的源库结构（也规避了 E 盘写不了的问题），结构调整全部落在 **category / tags / 新增题材池** 这三个字段上。
